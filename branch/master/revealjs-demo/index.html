Breaking slides¶

A section can be split into several slides with an explicit revealjs-break directive (MyST: :::{revealjs-break}), which emits a marker and starts a new slide – in every configuration:

This paragraph is in the first slide of this section.

This paragraph is in a second slide: the directive above forced a break. On the normal page the marker shows as a horizontal rule.

A ---- transition line (at least four dashes) splits slides the same way (revealjs_break_on_hr, on by default). The quieter ... divider instead introduces audience notes – see Audience notes below. Note that three dashes (---) are not a transition in reST – they render as a plain paragraph.

Audience notes¶

By default (revealjs_ellipsis_notes = True), a line containing only ... ends the slide’s presented content: everything up to the next divider, heading or explicit break becomes audience notes for the preceding slide. Readers see them as ordinary text on the normal page (the divider shows as a lone ellipsis – a quiet thought break), the slide itself shows nothing after its presented content, and the speaker view (S) lists them below the slide’s real revealjs-notes talk track, separated from it by a horizontal rule.

Speaker notes¶

The revealjs-notes directive attaches hidden speaker notes to the slide it appears in. They are invisible on the slide and in the normal page; press S during a presentation to open the speaker view, which shows the current and next slide plus the notes.

Theme from the URL¶

A valued revealjs parameter overrides the theme configured with revealjs_theme: ?revealjs=simple presents with the vendored simple theme, ?revealjs=none always presents unthemed. Only themes vendored under _static/revealjs/upstream/theme/ can be selected; an unknown name loads no theme, and the deck simply presents unthemed. This demo’s conf.py leaves revealjs_theme at its default 'none', so plain ?revealjs is already unthemed – try ?revealjs=simple for a themed deck. Unthemed decks scale their text from the page’s own font size (revealjs_font_scale); themed decks keep the theme’s fixed sizes.

Per-page options¶

The revealjs-options field at the top of this page enables slide numbers for this deck only (visible in presentation mode). Its value is a JSON object; it overrides the site-wide revealjs_options setting and is removed from the rendered page. In reST it is a docinfo-style field at the top of the page; in MyST a front-matter key whose value is a JSON string:

:revealjs-options: {"slideNumber": "c/t"}

With several revealjs-options fields, the last one wins.

Printing and resuming¶

Load the deck with &print-pdf in the URL (for example revealjs-demo.html?revealjs&print-pdf) and print to PDF from the browser (landscape, margins: none, background graphics: on) to get a handout with every slide on its own page. Plain browser printing (without print-pdf) also works and produces a simplified text layout of the whole deck.

The deck also remembers where you stopped reading: re-entering the presentation reopens on the last viewed slide (per page, stored in the browser’s local storage). A #/2/0 style hash in the URL takes precedence.
